product image reports the exact secureblue Fedora 45 identity recorded by

## Fixed non-root bootc-status bridge

The qualification driver no longer invokes privileged bootc status directly.
It requires the root-owned `/run/symbi-qualification/status.sock` and reads one
report before and one after the upstream suites. The new `q.service` can execute
only `/usr/bin/bootc status --json`; its server accepts exactly two non-root
connections, requires an empty request stream, caps each response at 128 KiB,
rejects duplicate JSON keys and removes only the socket inode it created.

The collector has private PID, mount and network namespaces, no-new-privileges,
only `CAP_SYS_ADMIN`, 256 MiB memory, half a CPU, 32 tasks and zero swap. The
driver receives boot metadata only and gains no command, sudo or policy-changing
interface. Both reports still need the exact digest-pinned OSTree deployment and
`containerPolicy` reference.

The missing-module fail-first result and 13 passing focused tests are retained
in `P0-04-status-socket-before.log` and `-after.log`. The final serial gate
passes 280 image tests, 13 Landlock tests, six Cedar tests and the Rust,
supply-chain and formal drift gates in 3.36 seconds at 70,040 KiB peak RSS, one
Cargo job and zero swap. Native guest execution remains pending.
