## Scope

Establish a Rust 1.89.0 workspace, the `symbi-common` crate boundary, a schema
skeleton derived from the plan's `model.invoke` example, base policy with no
permits, real Cedar CLI integration tests, cargo-deny/vet configuration, a

is retained in `docs/build-plan.md` with the card claimed.

## Threat note

A compromised build or policy-test tool can alter developer/CI artifacts and
falsify test results. Pinning limits accidental drift, but does not authenticate
an OS release or establish trusted input. The CI workflow uses no release
credentials and disables checkout credential persistence. It runs untrusted PR
code and therefore requires an isolated, unprivileged runner with no signing
keys. The schema is input structure only; its fields are not trusted assertions.
