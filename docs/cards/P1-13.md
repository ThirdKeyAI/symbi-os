## Scope

Keep Tolaria's desktop vault human-owned while exposing a small governed service
for agents. A vault is an explicitly selected Git repository containing Markdown
and YAML frontmatter. Read contracts name exact operations and never expose an
arbitrary shell or path outside that vault. Write contracts create or reuse a
private branch/worktree, commit the proposed change there and return a bounded
diff. Applying that diff to the human branch is a separate approval. The service
cannot push, merge, approve itself, set the session class or edit agent
configuration.

The desktop application ships from the patched P0 source build. Its updater,
writable loopback bridge, direct model-provider routes, direct agent launches,
runtime package downloads and durable harness-configuration writes remain
disabled. A later service manifest may publish the same reviewed contracts; it
must not restore those application-side routes.

## Acceptance criteria

- [ ] First launch asks the human to open or create a vault and does not silently
  create one under the home directory.
- [ ] The human can open an existing vault, edit a Markdown note and make a Git
  commit from the desktop app without network access.
- [ ] Named read contracts cover note listing, bounded search, note reads and Git
  status/history; path traversal, symlinks out of the vault and Git alternates are
  refused.
- [ ] Every agent write occurs in an isolated branch/worktree and returns a diff
  before the real branch changes.
- [ ] Rejecting the diff leaves the human branch and worktree unchanged. Applying
  it requires the human-approved action and records the exact commit/diff hash.
- [ ] The service has no push, merge, remote-management, raw shell, arbitrary Git
  command or session-class operation.
- [ ] Vault text is treated as untrusted data and cannot become policy, grants or
  instructions merely by being read.
- [ ] The user's real agent configuration remains byte-for-byte unchanged.
- [ ] Revocation or freeze interrupts an in-flight read/write and leaves either a
  complete journaled commit or no effect.
