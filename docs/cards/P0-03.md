## Actual build-tool acceptance in progress

The dedicated hosted workflow now specifies tests against an unmodified, exact
BlueBuild source build, with recipe v2 explicitly enabled. Source inspection
found that both v0.9.42 and the selected post-release revision still validate
against v1; no passing CLI/build claim is made. Positive generic/NVIDIA recipes
must pass, malformed or unpinned profile cases must fail for a validation reason,
and Containerfile generation must run without bypass flags. See
[the hosted tool procedure](../../image/README.md#hosted-bluebuild-compatibility-check).
Compilation runs off the workstation, under a 4 GiB/two-CPU/zero-swap hosted
cgroup and 45-minute limit. The workflow has no signing or publication authority.
