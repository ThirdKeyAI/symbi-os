# Retained portal runtime input checks

The small tests exercise archive/path/hash/source/test-report bindings and the
selection of only the authenticated iniparser runtime provider. Runtime result
checks reject incomplete loaders, incorrect version, privileged identity,
missing package-signature negative controls, changed resource limits and OOM
events. The before logs capture missing implementations; the after logs and
full 183-test validation pass. These synthetic checks are not native runtime
or screen-sharing consent evidence. The original hosted build and its failure
are reconciled separately in `../P0-03-portal-build/45773194827/`.
