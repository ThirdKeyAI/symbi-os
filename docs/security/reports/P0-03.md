privacy files and renderer tests failed because those files did not exist.

existing settings and links, refusal of unsafe directory/source links, digest
and key-hash validation, and the intended privacy defaults. Seven vendored files
match their retained SHA-256 values. These tests do not verify OCI signatures.

keys exist only inside temporary test fixtures and are never recipe defaults.

`image/THIRD_PARTY.md`), including its actual `bluebuild: none` setting. The CLI
and generated Containerfile have not been exercised: recipe v2 is a compile-time
feature and the selected runner must qualify the actual pinned executable.

70,348 KiB (about 69 MiB); it is retained in `P0-03-check.log`. The formal
verification drift check also remains in sync. No VM,
