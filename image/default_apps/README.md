# Requested terminal applications

This directory binds the first reviewed candidate versions for Yazi, Glum and
Tootles. They are selected desktop requirements, but they are not installed or
qualified in the current images. A later hosted intake must authenticate the
exact release/source payloads, retain license and SBOM data, build or unpack
without network access, and run installed-image acceptance on both variants.

Yazi is the terminal file manager launched in Kitty. The immutable profile ships
no downloaded plugins or themes and disables its runtime package download path.
Glum is the local terminal Markdown reader. Tootles is the human's Mastodon and
Bluesky client, starts with Tokyo Night, and may use the already-requested mpv
for explicit media playback. Tootles real-account support stays blocked until
its credentials are stored through a qualified secret boundary and cannot enter
governed sessions.

The convenience installation commands in upstream documentation are not OS
build inputs. Exact artifacts, signatures, provenance, dependency closures and
native package compatibility remain unresolved.
